Behind the Website

This portfolio wasn't bought off a template shelf. Every line of code, every design decision, every interaction was built from scratch — entirely through conversation with an AI. Here's how it happened.

How It Was Built

Step 01

The Idea

Rather than submit a standard PDF application, I decided to build a custom portfolio website specifically for this application to Commerzbank. The goal: demonstrate initiative, technical curiosity, and attention to brand detail — all qualities relevant to the role.

Step 02

Design Philosophy

The entire visual identity is built around Commerzbank's brand colours — navy (#002e3d) and yellow (#fcd202) — with DM Sans as the typeface. Three font sizes throughout. The design is intentionally clean: no clutter, no noise, just structured information with deliberate visual hierarchy.

Step 03

The Scratch-to-Reveal Landing

The index page uses an HTML5 canvas to simulate a scratch-card mechanic. The background photo is drawn onto the canvas layer; scratching erases it with a yellow brush to reveal the navy welcome screen underneath. 25% scratch coverage triggers the full reveal. It's a small detail, but details matter.

Step 04

Split-Screen Layout & YouTube Integration

Every content page uses a sticky split layout: a looping background video fixed on the left, scrollable content on the right. Below each section, a YouTube embed (also sticky) lets viewers watch a personal video while reading — the text in the video panel mirrors the section above it exactly.

Step 05

Backend & Hosting

Developed and tested on GitHub Pages (static). For the live Ionos deployment, PHP endpoints handle file upload, listing, download and deletion — enabling the hiring team to download CV and supporting documents directly from the Data page. No database needed: files are stored on disk.

Step 06

This Page

The Q&A board below uses browser localStorage to persist questions and answers across sessions — so if you leave a question, it will still be here when I visit. I can reply from the same interface using an owner passphrase. A simple but effective two-way communication layer.
