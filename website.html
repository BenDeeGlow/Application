Behind the Website

This portfolio wasn't bought off a template shelf. Every line of code, every design decision, every interaction was built from scratch — Here's how it came together.

How It Was Built

Step 01

The Idea

Rather than submit a standard PDF application, I decided to build a custom portfolio website specifically for this application to Commerzbank. The goal: demonstrate initiative, technical curiosity, and attention to brand detail — all qualities relevant to the role.

Step 02

Design Philosophy

The entire visual identity is built around Commerzbank's brand colours — navy (#002e3d) and yellow (#fcd202) — with DM Sans as the single typeface. Three font sizes throughout. Clean, structured, deliberate.

Step 03

The Scratch-to-Reveal Landing

The landing page uses a two-layer HTML5 canvas. A solid yellow layer sits below; the photo sits on top and gets erased on interaction, revealing yellow beneath. Once enough is cleared, the welcome screen fades in.

Step 04

Sticky Split Layout & YouTube

Each content page has a sticky YouTube embed on the left while the right side scrolls. The video panel text mirrors the page content — so visitors can watch and read simultaneously.

Step 05

Backend & Hosting

Developed on GitHub Pages (static). On Ionos, PHP endpoints handle file upload, listing, download and deletion — enabling CV and document sharing via the Data page without any database.
