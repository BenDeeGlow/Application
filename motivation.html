The Website

Step 01 — The Idea

Rather than submit a standard PDF application, I built a custom portfolio website for this application to Commerzbank — to demonstrate initiative, technical curiosity, and attention to brand detail.

Step 02 — Design & Build

Built in HTML, CSS and vanilla JavaScript. Visual identity uses Commerzbank's navy and yellow throughout. The landing page features a two-layer canvas scratch-to-reveal interaction.

Step 03 — Hosting & Backend

Static content on GitHub Pages. PHP endpoints on Ionos handle document upload, download and deletion — and persist the Q&A board across devices.
